# v0.4.0b5 - Clearer Window Restoration Status

Heating pre-release for Home Assistant 2026.9 or newer.

## Changes

- Show Restoring heating/cooling instead of Windows open during restoration.
- Show a fresh HomeKit target matching the saved mode, explicitly labeled as
  locally reported while Ecobee confirmation is pending.
- Show the saved heating source as restoration intent, for example
  Restoring Gas furnace, without claiming confirmed fuel or running equipment.
- Keep source buttons unselected while restoration is pending.

This is a status-display update. Equipment commands, source selection,
window delays and restoration confirmation guards are unchanged.
The resolved Climado target remains unknown until confirmed. Stale, missing,
invalid, wrong-mode and Off local observations do not provide a display target.
HomeKit still cannot distinguish gas furnace from heat-pump heating.

## Installation

Install v0.4.0b5 through HACS, restart Home Assistant, and refresh the dashboard.
Existing automatic Windows configuration and delay settings are preserved.

## Validation

246 backend tests and 37 card tests pass. Simulated browser checks pass at
320, 390 and 1100 pixels, including local target display, unconfirmed fuel intent,
stale-feedback fallback and unchanged control guards. No live equipment was
operated to validate this display change.
