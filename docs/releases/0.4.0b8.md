# v0.4.0b8 - Automatic Fuel Status

The card now shows **Automatic - Gas furnace** or **Automatic - Heat pump**
directly below the heating-source controls, with a separate activity status.
An idle selected furnace is not presented as running. HomeKit activity does not
determine fuel; source selection still comes from Ecobee's fuel feedback.

During a handoff, the card shows the intended next source as **Switching to...**
until confirmed. Windows pauses and missing or conflicting source feedback have
distinct statuses instead of an assumed active source.

This is a display-only update. Fuel-selection policy, heating targets, fan
settings and equipment commands are unchanged. It includes the ULO/TOU selector
and published energy-only price display from v0.4.0b7.

Verification: 43 card tests, including both fuel sources, idle/heating/fan
activity, changeovers, unavailable feedback and pauses; browser checks at mobile
and desktop sizes. Live verification reads status without forcing a source change.
