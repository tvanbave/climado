# v0.4.0b4 - Automatic Windows Pause

Heating pre-release for Home Assistant 2026.9 or newer.

## Changes

- Opt-in automatic ventilation pause using selected window and patio-door contacts.
- Adjustable five-minute continuous-open and two-minute all-closed defaults.
- Separate manual and automatic pause ownership, preserved across restart.
- Missing contacts prevent automatic restoration; manual pauses remain manual.
- Card status shows open contacts and pause/resume deadlines.
- Stale indoor observations are marked explicitly, with exact freshness refreshes.
- Disabled heating-cost advice now shows a collapsed setup checklist.

Existing fan settings, HVAC mode restoration and heating source are preserved.
Automatic fuel switching remains disabled. No tariff or equipment-performance
inputs are silently applied.

## Setup

After installing, restart Home Assistant and refresh the dashboard. In Climado
options, select only ventilation contacts and enable automatic Windows monitoring.
Existing installations remain opted out until configured. Delay settings are
Configuration number entities on the Climado device.

When enabled, the card's window switch becomes Manual windows pause. That switch
does not clear an automatic pause. Disabling monitoring during an automatic pause
retains a manual pause for explicit release.

## Validation

242 backend tests and 32 card tests pass. Simulated browser checks pass at
320, 390 and 1100 pixels. Physical patio-door validation remains pending.

## Rollback

Disable automatic monitoring in Climado options. If it was paused, close all
openings and explicitly clear the retained manual pause when ready to resume.
Reinstall v0.4.0b3 through HACS and restart Home Assistant if rollback is needed.
The retained legacy active/restore storage fields keep any outstanding pause
visible to v0.4.0b3; do not clear it without checking the openings.
