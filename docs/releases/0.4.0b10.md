# v0.4.0b10 - Heading Home Availability

Heading home is now selectable only while Climado is in Away or Vacation,
including automatic Away. The card uses a neutral button until pre-arrival is
active, then highlights it. Home, Sleep, an active pre-arrival timer, windows
pause/restoration and pending source changes disable the action.

The button rechecks eligibility in the integration. A successful press clears
manual Away/Vacation and the Vacation switch, selects Auto, and starts the
seasonal pre-arrival target. Previously these away holds could outrank the
pre-arrival request. Arrival ends pre-arrival early; timer expiry returns to
normal Auto behavior, including Away if the house remains empty.

Existing `climado.start_pre_arrival` service calls retain their behavior.
No live HVAC changes are required to validate the button's availability.

Verification: 326 backend tests, 45 card tests and browser checks passed.
Coverage includes manual Away, automatic Away, both Vacation controls, heating
and cooling targets, expiry, duplicate presses and disabled/pending guards.
