# v0.4.0b12 - Morning Fuel Changeover and Sleep Heating Target

- At the end of ULO, Climado checks for a change to gas before applying the
  scheduled Home temperature increase. It lets a running heat-pump cycle
  finish at its existing target, retains the minimum dwell and five-minute
  equipment rest, and waits for fuel confirmation. Before a handoff, missing
  reports can defer the increase for up to five minutes; normal comfort
  control then resumes without forcing an unverified fuel change.
- Heating targets now includes a saved Sleep temperature. Set the value, then
  enable **Use Climado Sleep target** to apply it during scheduled or manual
  Sleep. By default the switch is off and Ecobee's native Sleep comfort
  setting remains in use. Cooling and Ecobee sensor configuration are unchanged.
- The card distinguishes saved profile temperatures from the active target
  and explains when a scheduled Home increase is waiting for gas.

Install the exact pre-release via HACS and restart Home Assistant. Refresh the
dashboard to load the updated card.
