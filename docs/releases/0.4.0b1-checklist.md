# 0.4.0b1 Heating Pre-release Checklist

Prepared for pre-release on 2026-10-05. Installation in the user's Home Assistant
and live equipment validation remain pending. No live heating commands were
issued during this work. This pre-release requires Home Assistant 2026.9 or newer. Automated tests use that
runtime; equipment checks below must be completed before a stable release.

## Included

- Opt-in heating comfort targets and native Ecobee Sleep.
- Manual System mode and next heating-source selection on the card.
- Restart-persistent pending system commands with no automatic replay.
- Windows open pause/restoration and explicitly inactive System off status.
- Configurable heating alerts and HA notifications, with no automatic override.
- Observation-only cost estimates and recommendation-change logging. No default
  COP curve or current tariff is silently installed. The historical gas preset
  expired October 1 and is not valid for new recommendations.

## Before Installation

- [ ] Confirm HA version meets the minimum; take an HA backup and record the
  installed Climado version, thermostat mode/source and Windows open state.
- [ ] Confirm the GitHub pre-release tag v0.4.0b1 is available before installation.
- [ ] Install the pre-release via HACS, restart HA and reload the dashboard.
- [ ] Verify installed manifest/card versions and no Climado startup errors.
- [ ] Review heating Home/Away/Vacation/pre-arrival values before opting in.
  Confirm Ecobee Sleep's heating target and bedroom sensor assignment.
- [ ] Confirm alert thresholds and notification preferences. HA notifications
  are not phone push notifications and are not independent freeze protection.

## Supervised Equipment Checks

Only run with the owner's approval, closed windows, and a person available to
observe the system. Do not bypass equipment lockouts or protections. Record
initial settings and return to the agreed operating mode after testing.

- [ ] Turn Windows open off; verify restoration completes. A previously Off
  thermostat must remain Off, with that state explicit on the card.
- [ ] From confirmed Off/idle, choose Heat pump then Heat. Verify actual
  compressor heating, selected source, target, sensor and eventual shutoff.
- [ ] Return to Off, wait for actual equipment stop and its required lockouts,
  then choose Gas furnace and Heat. Verify actual furnace operation and shutoff.
- [ ] Verify no Aux OFF request restores an unintended Heat/Cool mode.
- [ ] Verify Home, Away, Sleep, next-morning Auto recovery and pre-arrival.
- [ ] Open/close the Windows pause for each source; verify source restoration,
  current comfort target and unchanged periodic fan settings.
- [ ] Verify a restart while paused preserves the original source and mode.
- [ ] Review normal-cycle observations before tuning poor-progress alerts.
  Use automated simulations, not deliberately cooling the home, for low-temp
  alert and command-failure tests.

## Still Excluded

Automatic Heat/Aux handoffs, outdoor capacity/lockout enforcement, automatic
failure fallback, heating preheat/coast tariff optimization and seasonal
Heat/Cool changeover. The pure fuel policy is simulation-only. These require
confirmed installed equipment/performance data and supervised validation.
